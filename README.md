# 圆桌助手

一款服务线下阿瓦隆桌局的 Web 助手。它负责身份分配、秘密任务票、规则判断和进度记录；发言、组队讨论、现场举手、观察反应和刺杀指认仍由玩家面对面完成。

![手机首页](product/design/concepts/waiting-room.webp)

## 当前能力

- 5 至 10 人创建和加入桌局，支持房间号与二维码；
- 经典、进阶角色组合及两种连续否决规则；
- 私密身份查看与正确的角色已知信息；确认后仍可随时按住复看，松手立即隐藏；
- 队长选人过程实时同步到所有玩家和公共屏；现场举手不设倒计时，只由本轮真人队长记录反对人数，流程体验遇到模拟队长时由房主代记；
- 成功票与失败票不使用可偷看的区分颜色，上下顺序按玩家和轮次稳定变化；正义方仍能看到失败票，但不能选择；
- 全部任务票封存后由本轮队长确认，等待 3 秒再统一揭晓，并支持双失败规则；
- 三次成功后的刺杀、三次失败结算和全员身份公开；
- 刷新、短暂断线或误关网页后，可从首页“继续上次桌局”回到原座位、身份和当前进度；
- 开局前换空座位，结算后原座位再来一局；
- 等候阶段可主动离开，房主可移出其他真人玩家或解散房间；开局后房主可保留座位、清空本局并返回候场；
- 两台手机可使用“流程体验”，由三名模拟玩家补齐完整五人局；
- 房主可随时打开“房主管理”，让另一台电脑、平板或电视扫码进入只显示公开信息的公共桌面。
- 手机和公共桌面采用浅色自适应布局；手机圆桌会把座位、队长标记和选中状态完整包含在自身区域内，不会侵入上方标题或下方操作区；主要按钮、座位名和说明文字保持可触控、可阅读。
- 公共桌面使用接近全宽的横向椭圆圆桌，阶段信息显示在桌心留白，座位与任务轨道使用适合电视和投影观看的大字号；矮屏平板仍不产生页面滚动。

## 界面布局约定

- 手机游戏阶段按照“任务进度、阶段标题、可伸缩内容区、底部操作”相对排布，不用固定坐标把几块内容硬叠在一起。
- 手机圆桌的组件边界必须覆盖桌面、全部座位、队长标记和当前玩家提示；屏幕变矮时优先减少装饰和间距，不把主要文字缩到难以阅读。
- 主要触控区域不小于 44 像素；组队页座位名不小于 12 像素，按钮文字不小于 15 像素。
- 公共屏以横屏电视、电脑和投影为目标：椭圆座位区域至少利用约 70% 的横向空间，桌心信息、二维码、玩家名和任务进度随屏幕放大。
- 公共屏浏览器检查覆盖 5 至 10 人及 12 种横屏尺寸，包括 1920 × 1080 和 2560 × 1440；完整结果以 [测试报告](product/QA.md) 中明确记录的当次回归为准。

## 本地运行

需要 Node.js 22 和 pnpm。

```bash
pnpm install
pnpm dev
```

打开 `http://localhost:4173`。同桌其他设备需要通过一个它们也能访问的地址打开网页；正式使用时建议部署到 HTTPS 域名。

## 检查与构建

第一次运行浏览器检查前，先安装测试浏览器：

```bash
pnpm exec playwright install chromium webkit
```

```bash
pnpm test:all
```

也可以分别运行：

```bash
pnpm lint
pnpm typecheck
pnpm test:coverage
pnpm test:e2e
pnpm build
```

正式启动构建结果：

```bash
pnpm build
pnpm start
```

可通过 `PORT` 修改端口，通过 `ROOM_TTL_HOURS` 修改无活动房间的保留时长。

## 使用 Docker 部署到只有 IP 的服务器

项目已经提供 `Dockerfile` 和 `compose.yaml`。默认把服务器的 80 端口映射到应用，部署后直接访问：

```text
http://服务器IP
```

先把整个项目目录上传到服务器，然后在项目目录执行：

```bash
docker compose config
docker compose up -d --build
docker compose ps
```

确认服务正常：

```bash
curl http://127.0.0.1/api/health
```

正常时会返回包含 `"ok":true` 的结果。还需要在云服务器安全组中开放入站 TCP 80；不需要对外开放 4173。

常用维护命令：

```bash
# 查看最近日志
docker compose logs --tail=100

# 持续查看日志
docker compose logs -f

# 上传新代码后重新构建并更新
docker compose up -d --build

# 停止并移除容器
docker compose down
```

房主打开 `http://服务器IP` 创建桌局，其他玩家扫码加入。二维码会自动使用当前 IP 地址；房主进入“房主管理—公共屏”，可让另一台设备扫码进入，也可在本机预览。

该方案使用 HTTP，浏览器可能显示“不安全”。不要填写真实敏感信息。容器更新、重启或服务器重启会结束正在进行的桌局，因此请避开游戏过程中更新。
