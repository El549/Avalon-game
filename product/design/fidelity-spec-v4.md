# 圆桌助手个人手机页视觉基准 v4

本轮废止 `mobile-team-building-v2.png` 的圆形座位与繁复装饰。个人手机页以
`product/design/concepts/mobile-team-building-v3.png` 为新的组队页视觉基准；公共屏继续沿用 v3 规范，不随本轮改动。

## 设计目标

- 第一眼先看到当前任务，其次看到可操作玩家，最后看到确认动作。
- 页面保持真白背景、深海军蓝主色和克制古金色；不使用渐变、玻璃、厚重双线或装饰性菱形。
- 控件、提示和玩家姓名使用系统黑体；品牌可保留少量宋体气质，但不得影响阅读。
- 所有状态都有唯一含义：深蓝底表示已选，`队长`只表示本轮队长，`我`只表示当前设备玩家。

## 页面结构

1. 顶部栏高度稳定在 60～68px，使用“品牌 / 房间信息 / 操作”三段结构。
2. 房间名称与房间号作为一个整体，可上下排布；不得把所有信息挤成一行。
3. 阶段标题使用简洁黑体“第 N 轮 · 选择队员”，不再添加左右装饰线。
4. 圆桌舞台、选择计数和按钮平均分配剩余高度，不得在圆桌下方出现大块无意义空白。
5. 主按钮使用单层深蓝底、细金边和轻微阴影；不再使用渐变、双层描边和菱形装饰。

## 玩家座位组件

- 5～7 人使用沿圆桌排布的横向铭牌，号码在左、完整姓名在右。
- 8～10 人使用圆桌框内的双列紧凑名册，避免把姓名缩成不可读的小字。
- 5 人常见姓名目标为单行；较长昵称允许自然换为两行，不允许省略号或任意逐字断行。
- 座位组件最小触控尺寸为 48px，高度不得因姓名长短发生变化。
- 已选状态只使用深蓝底、白字和一个内收的勾选标记。
- 队长使用一个小型金色 `队长` 标记；当前玩家使用一个小型 `我` 标记。
- 号码、姓名、勾选、队长、当前玩家和边框之间必须保留明确间距，不得悬浮叠压。
- 组队阶段隐藏“模拟 / 离线”等与选择无关的信息；这些信息只在候场管理语境中出现。

## 响应式规则

- 360×640、375×667、390×844、430×932 均保持一屏操作，不出现页面滚动。
- 5～10 人、中文 12 字昵称、连续英文昵称和中英混合昵称都要完整可见。
- 360×640 只压缩纵向间距、桌面大小和次要说明，不降低姓名到 12px 以下，不隐藏主操作。
- 宽度变化通过铭牌宽度、圆桌轨道和密集布局切换处理，不靠负边距把组件推出屏幕。

## 硬验收

- 所有玩家姓名逐字检查，不得被裁切、省略或被其他标记遮挡。
- 所有座位组件检查可见边界与触控边界，任何两张铭牌不得相交。
- 队长、当前玩家、已选三种状态必须可以在三秒内分辨，且组合状态也不能发生碰撞。
- 标题、圆桌、选择计数和按钮之间不得重叠，视觉间隔不得大于相邻主要区块高度的一半。
- 队长点击玩家后，其他手机实时看到相同选中状态；确认按钮状态与选择数量一致。
- 最终必须把 v3 概念图、360×640 实现截图和 390×844 实现截图放在同一轮目测中对照。
